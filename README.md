# 4sell.ai — лендинг

Интерактивный лендинг 4sell: ИИ-помощник, калькулятор роста, экосистема, партнёры, кейсы и контакты.

## Сайт

[Открыть лендинг](https://aventadxr.github.io/4sell-landing/)

## Локальный запуск

Откройте `index.html` в браузере. Зависимости и сборка не нужны: сайт использует HTML, CSS и JavaScript, все ресурсы находятся в `assets/`.

Для запуска через локальный HTTP-сервер:

```sh
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация

GitHub Pages публикует корневую папку ветки `main`. После отправки изменений в эту ветку GitHub автоматически обновляет сайт. Файл `.nojekyll` включает публикацию готовых статических файлов без обработки Jekyll.

## Демонстрационный режим

Форма обратной связи показывает анимацию отправки, но не отправляет и не сохраняет данные. Отзывы и примеры работы ИИ демонстрационные; параметры калькулятора описывают изменяемый сценарий.
